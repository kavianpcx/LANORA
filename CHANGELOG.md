# Changelog

This project follows Semantic Versioning when releases begin. During development, entries describe repository state and do not imply a published binary.

## Unreleased (0.1.0 development)

### Added
- Go API account registration, login, profile update and logout endpoints.
- React/Vite web application with Persian RTL account, room, status and settings flows.
- GitHub Pages build/deployment workflow source and CI workflow source.
- Self-hosting, API, architecture, security, networking, installation, build and troubleshooting guides.
- Original LANORA SVG branding and repository community templates.

### Limitations
- No EasyTier client integration, Windows virtual adapter, installer, verified tunnel, or binary release.
- No end-to-end two-client network tests have been verified.
- API and Docker deployment checks must run in CI/host environments with Go and Docker installed.

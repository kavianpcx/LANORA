# Installation

For the server, use [Self-hosting](SELF_HOSTING.md). For Windows, download the NSIS installer from [GitHub Releases](https://github.com/kavianpcx/LANORA/releases) after its build succeeds. The release must say it is experimental. Windows 10/11 x64 and privileges needed to create a virtual adapter are expected. The bundle includes EasyTier v2.6.4 and notices. Linux x64 (Debian/Ubuntu) will use a `.deb` package after a successful CI build; installation configures limited network capabilities on the bundled EasyTier core and requires administrator permission. No browser app is required. To build from source, see [Building](BUILDING.md).

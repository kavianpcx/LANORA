# Roadmap

## Current alpha: 0.2.0-alpha.3

- Default flow enters a server URL and shared access code, then automatically joins one server-wide EasyTier network.
- Server-backed app presence, native EasyTier virtual IP, and actual CLI-reported peer routes are shown as separate signals.
- Windows installer and Linux Debian package are generated by GitHub Actions.
- Linux namespace integration verifies the shared API path and real TCP/UDP relay traffic.

## Still unverified

- Two independent computers on public internet connections.
- Windows virtual adapter initialization, firewall behavior, and game traffic.
- Direct P2P/NAT traversal across consumer routers.
- Popular game-specific LAN discovery, broadcast and multicast compatibility.
- Recovery behavior on extended real ISP outages.

## Next

- Test the Windows tunnel on two separate machines and capture route, firewall, relay/direct, and game-level evidence.
- Improve peer and relay diagnostics from data the native engine can actually provide.
- Keep the default connection flow to server address, authorization, and connect.
- Retain room-based workflow only as an advanced option until real users need it.

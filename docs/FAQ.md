# FAQ

**Do players need an account?** No. Choose a display name in Settings and enter the server address.

**What does the VPS do?** It hosts the API and EasyTier shared node. It manages rooms and provides a path for relay, but the API does not carry all game packets.

**Which IP goes into the game?** The game host player's virtual IP shown by EasyTier in LANORA, not the VPS public IP.

**Does the room list show who is online?** It shows approved/pending membership counts, not verified live tunnel presence.

**Will every LAN game work?** No. Direct IP is more predictable; broadcast and multicast discovery vary and have not been verified.

**Is there a website?** No. Download the Windows or Linux installer from GitHub Releases when a verified build is available.

# LANORA 0.2.0-alpha.8

Experimental prerelease focused on connection feedback and diagnostic accuracy.

- Reject blank server addresses locally with a friendly inline message and focus the server address field.
- Infer HTTP for bare loopback development addresses (`localhost`, `127.0.0.0/8`, and `::1`). Public addresses continue to default to HTTPS; non-loopback HTTP is rejected.
- Distinguish empty, malformed, unsupported-protocol, timeout, unreachable, invalid-response, and exposed TLS-certificate errors in the desktop client.
- Compact connected player rows, label only measured server and peer RTT, improve the red-accented Power Disconnect action, and provide accessible copy buttons with transient success feedback.
- Show partial peer-route reachability as a count, distinguish observed relay routes from an independent relay test, and label stale app-presence/peer data.
- Whitelist copied diagnostic fields so server URLs, player IPs, membership IDs, tokens, and network secrets are excluded.
- Preserve all 17 avatar IDs and existing WebP artwork; remove one unused avatar fallback helper and its obsolete CSS.

## Verification limits

Frontend automated tests and the Vite production build pass in the available environment. This environment could not run Go, Cargo/Tauri, Docker, or the Windows installer toolchain. The UI preview browser could not reach the container's local Vite port. A real localhost Go backend request, native Windows installation, Windows display-scaling checks, two independent Windows PCs, peer reachability, real game TCP/UDP traffic, and direct/relay fallback were not verified here. This is a prerelease, not a stable release.

Server RTT is the measured API request round-trip. Peer RTT and route type are separate EasyTier observations. API session revocation cannot immediately evict a modified client already connected to an old EasyTier overlay; players should fully disconnect and rejoin after access-policy changes.

# LANORA 0.2.0-alpha.8

Experimental prerelease focused on connection feedback and diagnostic accuracy.

- Reject blank server addresses locally and focus the address field.
- Infer HTTP for bare loopback development addresses; public addresses continue to default to HTTPS, and plaintext HTTP to non-loopback hosts is rejected.
- Improve address, network, timeout, invalid-response, and exposed TLS-certificate errors in English and Persian.
- Refine connected player rows, disconnect/copy controls, measured server and peer RTT, and stale presence labels.
- Show partial peer-route reachability as a count and separate observed relay routes from independent relay checks.
- Whitelist copied diagnostic fields to exclude server URLs, player IPs, membership IDs, tokens, and network secrets.
- Preserve all 17 avatar IDs and existing WebP artwork.

This release remains experimental. Multi-PC Windows connectivity, game TCP/UDP traffic, real VPS/relay reachability, P2P, and game-specific compatibility are not verified by the available environment.

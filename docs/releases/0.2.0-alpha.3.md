LANORA 0.2.0-alpha.3 is an experimental shared-network preview.

This release makes the server-wide shared network the default: enter the server address and access code, then LANORA joins automatically and shows its EasyTier virtual IP and peer routes when available.

Downloads:
- Windows x64 NSIS installer
- Linux x64 Debian package
- SHA-256 sidecars for both packages

Verification performed by this release workflow:
- API authorization and Go race tests
- desktop frontend and Rust native tests
- Windows installer build, install, application startup, and clean window close
- Linux package build/install and desktop launch
- two isolated Linux clients join through the shared API, receive distinct EasyTier virtual IPs, exchange TCP and UDP traffic through the local relay, and retain unchanged default routes
- Docker Compose deployment smoke test and server command checks

Still unverified: two separate computers on public internet connections, Windows tunnel/game traffic, direct P2P/NAT traversal, an external VPS relay, and game-specific LAN discovery. This is not a stable release.

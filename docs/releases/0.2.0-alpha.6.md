# LANORA 0.2.0-alpha.6

This experimental prerelease polishes the desktop client while preserving the optional player-password flow introduced in alpha.5.

## Desktop

- Add 17 bundled, original animal and character avatars with consistent sizing, selected preview, keyboard selection, Persian names, and stable legacy avatar IDs.
- Add a startup skeleton tied to actual desktop version and local network-engine initialization checks. Slow initialization is bounded; offline startup does not require server access.
- Show server, player authorization, and virtual-network connection stages without invented percentages. The connected screen now identifies the server and continues to distinguish API authorization, virtual-IP readiness, and measured peer routes.
- Assign stable local fallback avatars to other players. Avatar selections are still device-local because the server API does not synchronize profile avatars.
- Keep prior connection failures in the connection area instead of repeating them in Settings. Local profile changes remain local and report local-storage failures there.
- Preserve the existing password discovery behavior, HTTPS checks, themes, and fixed LTR application structure in Persian.

## Verification scope

CI runs desktop TypeScript tests, native Rust tests, Linux local-network smoke checks, and Windows/Linux package builds. Windows package installation and startup are checked in CI. This does not establish real peer-to-peer reachability between independent networks, Windows game-traffic routing, or game-specific LAN discovery. See the workflow run attached to this release for the exact result of each job.

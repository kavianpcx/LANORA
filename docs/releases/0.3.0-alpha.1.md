# LANORA 0.3.0-alpha.1

Experimental prerelease candidate for compact profile Settings, more accurate peer diagnostics, and signed Windows updates.

## Changes

- Settings now focuses on avatar, language, and appearance. Edit the display name from the titlebar profile menu; first-run onboarding and server-backed profile synchronization remain available.
- Keep the existing 17 avatar illustrations and saved avatar IDs while correcting picker sizing and owl artwork scale.
- Include players waiting for a virtual IP in peer summaries. A full route pass requires fresh player presence and fresh route evidence for every expected player.
- Distinguish measured server API RTT from EasyTier peer RTT and present Direct IP guidance only after a fresh peer route is observed.
- Add the official Tauri updater flow for signed Windows artifacts, including manual checks, opt-in installation, and real download progress.
- Fix Debian package validation so it checks the extracted post-install control file without a short-circuiting pipeline.

## Update installation

The existing `v0.2.0-alpha.8` application does not contain the updater and cannot update itself. Install this first updater-enabled release manually. Future compatible Windows prereleases use the embedded public key to verify their Tauri signature before installation. The updater does not force installation and asks before disconnecting from an active LANORA network.

## Verification limits

This prerelease must not be presented as stable. The updater needs a protected repository signing secret and a public repository variable. A successful package build and valid manifest do not replace a full installed-version-to-installed-version update test. Native Windows UI scaling, updater download/signature/install/relaunch behavior, two independent Windows PCs, external VPS connectivity, and game TCP/UDP traffic remain unverified until exercised on the relevant systems.

Changing player policy cannot immediately evict a modified EasyTier client that retained the old network secret. Ask players to disconnect and rejoin after policy changes.

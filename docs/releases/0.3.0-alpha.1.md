# LANORA 0.3.0-alpha.1

Experimental prerelease candidate for compact profile Settings, more accurate peer diagnostics, and signed desktop updates.

## Changes

- Settings now focuses on avatar, language, and appearance. Edit the display name from the titlebar profile menu; first-run onboarding and server-backed profile synchronization remain available.
- Keep the existing 17 avatar illustrations and saved avatar IDs while correcting picker sizing and owl artwork scale.
- Include players waiting for a virtual IP in peer summaries. A full route pass requires fresh player presence and fresh route evidence for every expected player.
- Distinguish measured server API RTT from EasyTier peer RTT and present Direct IP guidance only after a fresh peer route is observed.
- Use the official Tauri 2 updater for Windows NSIS and Linux Debian packages. Show real download progress, separate verification, installation and restart states, and confirm the installed version after relaunch.
- Keep signature verification enabled and bind signatures to the announced version.
- Fix Debian package validation so it checks the extracted post-install control file without a short-circuiting pipeline.

## Update installation

The existing v0.2.0-alpha.8 application does not contain the updater and cannot update itself. Install the first updater-enabled release manually. Later signed Windows and Debian releases use the same embedded public key and static GitHub manifest. A download or signature check never interrupts an active LANORA network; installation asks before disconnecting.

## Verification

This remains an experimental prerelease, not a stable release. The signed Windows NSIS installer and Linux Debian package are published with SHA-256 checksums, detached Tauri signatures, and the live alpha updater manifest. The production release workflow completed package build/install/launch checks, checksum validation, updater signature verification, and manifest validation before publishing.

The installed-version-to-installed-version update flow is still under separate Windows UI Automation testing. Release CI does not establish behavior on physical Windows or Linux desktops. Native Windows UI scaling, two independent Windows PCs, external VPS connectivity, and game TCP/UDP traffic remain unverified.

Changing player policy cannot immediately evict a modified EasyTier client that retained the old network secret. Ask players to disconnect and rejoin after policy changes.

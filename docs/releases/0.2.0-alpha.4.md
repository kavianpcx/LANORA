LANORA 0.2.0-alpha.4 is an experimental update focused on truthful connection state, credential handling and configurable deployment ports.

## Changes

- API health checks now use the configured `LANORA_LISTEN_ADDR`; Caddy can target a matching `LANORA_API_INTERNAL_PORT`.
- The desktop no longer persists the shared access code in localStorage and removes the legacy value at startup.
- Desktop status separates server reachability, access-code authorization, tunnel startup, virtual-IP assignment and evidence of reachable peers.
- Added regression tests for healthcheck-port parsing and connection-state transitions.
- Added best-effort network rotation instructions to the security documentation.

## Validation on this release candidate

- Go API tests with race detection: passed.
- Server management, repository checks, and Docker Compose deployment smoke test: passed.
- Desktop frontend and Rust tests on Windows and Linux: passed.
- Windows x64 installer build, installation, launch and normal close: passed in GitHub Actions.
- Linux x64 Debian package build, installation and native launch: passed in GitHub Actions.
- Two isolated Linux clients used the pinned EasyTier v2.6.4 relay path with P2P disabled and exchanged real TCP/UDP traffic; default client routes remained unchanged.
- Five direct connection-state model tests also passed under Node 24.

## Known limitations

This is not a stable release. Two physical Windows PCs on independent public networks, Windows game traffic, a public VPS relay, direct P2P/NAT behavior and game-specific LAN discovery have not been verified.

API token revocation cannot remotely erase a network secret already delivered to a running EasyTier client. Changing the shared access code and restarting the API rotates the network identity and clears API memberships, but trusted players must leave and rejoin before they are separated from the old overlay. A hostile client may continue communicating with any device that remains on that old overlay. Do not treat this as immediate kick/ban capability.

The desktop sidecar reads its network configuration from a local file containing the EasyTier secret. Unix file mode is restricted; the Windows ACL and cleanup after force-termination have not been verified.

# LANORA 0.3.0-alpha.2

Experimental maintenance prerelease. Publish only after frontend, Rust, API, Linux networking and Windows/Linux installer CI passes.

## Fixes

- Clicking an available-update notice opens update details and does **not** start downloading or installing. Use the explicit **Install update** button to begin installation.
- EasyTier peer rows with unknown or offline routing costs no longer count as evidence of reachability. Native Rust regression fixtures cover both cases.
- English and Persian README files include a genuine Linux first-launch screenshot captured during an earlier alpha CI smoke test; it is not a new Windows screenshot.
- Repository checks guard the update-notice behavior and screenshot link.

## Verification limits

This stays an experimental prerelease. Automated CI provides source, API, native tests, isolated Linux relay TCP/UDP traffic, and installer smoke checks, not proof of independent Windows PCs, game-specific LAN discovery, real public VPS networking, or a complete installed-version updater/restart cycle. Rotation of API sessions cannot forcibly terminate a modified EasyTier client still holding the old network key. See [security](../SECURITY.md) and [roadmap](../ROADMAP.md).
